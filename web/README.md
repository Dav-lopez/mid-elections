# CivicPulse Web

Isolated Next.js application for multi-country election coverage. Deploy as a separate Vercel project with Root Directory `web`.

Development: `npm install && npm run dev` from `web/`.

This initial page deliberately does not invent candidate rosters or vote totals. Country-specific verified ingestion and provenance will follow in separate reviewable PRs.

The existing Streamlit application (`app.py`) and deployment remain unchanged.
